# Match Recall

Guess the pro League of Legends series from its draft, bans, builds and trivia.

- English (switches to Korean on Korean browsers): https://matchrecall.lol/
- 한국어: https://matchrecall.lol/ko.html

These pages are built from a private repo; edit them there, not here.
Champion and item images come from Riot Games' Data Dragon. Match Recall isn't endorsed by Riot Games.
